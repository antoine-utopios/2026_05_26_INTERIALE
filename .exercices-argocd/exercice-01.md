# Exercice ArgoCD #1 - Récupération de manifestes K8s

## Objectifs

Appréhender le déploiement automatisé dans un cluster K8s via ArgoCD

## Sujet

Créer un dépot Git synchronisé avec une `Application` ArgoCD qui contiendra une application React conteneurisée et déployable dans un cluster K8s.

Le déploiement au sein du cluster K8s devra se faire via ArgoCD et sera réalisé par l'utilisation du bouton de synchronisation manuelle.
